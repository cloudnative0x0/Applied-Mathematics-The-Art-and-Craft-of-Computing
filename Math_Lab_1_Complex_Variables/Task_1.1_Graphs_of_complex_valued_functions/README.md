# Графики комплекснозначных функций

**Задача 1.1.** Построить графики функций $\mathrm{Re}\{\exp[(m+k\cdot i)\cdot x]\}$, $\mathrm{Im}\{\exp[(m+k\cdot i)\cdot x]\}$, где $m$ — номер группы (1 или 2), $k$ — Ваш номер в списке группы. Нужно построить графики на компьютере, сопроводив комментариями. Кривые построить разными цветами. Рисунок должна сопровождать легенда (какая кривая изображена). Отрезок, на котором строится график, нужно выбрать самостоятельно так, чтобы из графика можно было понять, как устроена функция в целом. Нужно объяснить свой выбор. Программный код нужно приложить. То же задание для функций $\mathrm{Re}\{\cos[(m+k\cdot i)\cdot x]\}$, $\mathrm{Im}\{\cos[(m+k\cdot i)\cdot x]\}$.

Муравьёв Герман

Цель: исследовать две комплекснозначные функции вещественной переменной $x$:

```math
f(x)=\exp((m+ki)x),
\qquad
g(x)=\cos((m+ki)x).
```

---
##### Комплекснозначные функции

Каждая комплекснозначная функция имеет вещественную и мнимую части.

Если $h(x) = u(x) + iv(x)$, тогда запишем:

```math
f(x) = Re(f(x)) + iIm(f(x)).
\qquad
g(x) = Re(g(x)) + iIm(g(x)).
```

где любая $Re(h(x))$ является $u(x)$, также любая $Im(h(x))$ ялвяется $v(x)$. Таким образом имеем 4 конечные функции для исследования:

```math
\mathrm{Re}f(x),\quad
\mathrm{Im}f(x),\quad
\mathrm{Re}g(x),\quad
\mathrm{Im}g(x).
```

### Решение

##### Находим вещественную и мнимую части комплексной экспоненты

Чтобы построить требуемые графики $Re(f(x))$ и $Im(f(x))$, представим комплексную функцию $f(x)$ в виде $u(x) + iv(x)$. Тогда выражение без $i$ будет вещественной частью, а коэффициент при $i$ – мнимой.

Рассмотрим функцию: $f(x) = exp((m + ki)x)$

Раскроем скобки, тем самым разделив вещественную и мнимую части показателя:

```math
(m + ki)x = mx + ikx.
```

Используем свойство $exp(a + b) = exp(a) \times exp(b)$ и рассмотрим функцию:

```math
f(x) = exp(mx) \times exp(ikx),
```

Вторым множителем является $exp(ikx)$, чтобы представить его в виде вещественной и мнимой частей, то применяем формулу Эйлера:

```math
\exp(i\varphi)=\cos(\varphi)+i\sin(\varphi).
```

В нашем случае $\varphi=kx$, поэтому

```math
\exp(ikx)=\cos(kx)+i\sin(kx).
```

Далее подставим $exp(ikx)$ в исходные функции и раскроем скобки:

```math
f(x) = exp(mx)\times(cos(kx) + isin(kx)),
```

```math
f(x) = exp(mx) \times cos(kx) + iexp(mx) \times sin(kx).
```

Сравниваем полученное выражение с формой $f(x) = u(x) + iv(x)$. Слагаемое без $i$ является вещественной частью, а коэффициент при $i$ – мнимой частью. Поэтому:

```math
Re(f(x)) = exp(mx)\times cos(kx).
```

```math
Im(f(x)) = exp(mx)\times sin(kx).
```

##### Находим вещественную и мнимую части комплексного косинуса

Чтобы построить требуемые графики $\mathrm{Re}g(x)$ и $\mathrm{Im}g(x)$, представим комплексную функцию $g(x)$ в виде $u(x)+iv(x)$. Тогда выражение без $i$ будет вещественной частью, а коэффициент при $i$ — мнимой частью.

Рассмотрим функцию:

```math
g(x)=\cos((m+ki)x).
```

Чтобы привести комплексный косинус к виду $u(x)+iv(x)$, выразим его через комплексные экспоненты. Эта формула следует из формулы Эйлера, представим в виде системы:

```math
e^{iz}=\cos z+i\sin z,
```

```math
e^{-iz}=\cos z-i\sin z.
```

Складывая эти равенства, получаем:

```math
e^{iz}+e^{-iz}=2\cos z.
```

Следовательно:

```math
\cos z=\frac{e^{iz}+e^{-iz}}{2}.
```

Везвращаемся к исследуемой функции:

```math
g(x)=\cos((m+ki)x).
```

Введем переменную (обозначим):

```math
z=(m+ki)x.
```

Тогда

```math
g(x)=\cos z=\frac{e^{iz}+e^{-iz}}{2}.
```

Для дальнейшего преобразования необходимо отдельно вычислить показатели двух экспонент: $iz$ и $-iz$.

Подставляем $z=(m+ki)x$ в выражение $iz$:

```math
iz=i(m+ki)x.
```

Раскрываем скобки:

```math
iz=(im+iki)x.
```

Так как $i\cdot i=i^2=-1$ (мнимая единица – основа комплексных чисел), получаем:

```math
iz=i(m+ki)x=imx+i^2kx=imx-kx=-kx+imx.
```

Аналогично вычисляем $-iz$:

```math
-iz=-i(m+ki)x=-imx-i^2kx=-imx+kx=kx-imx.
```

Теперь подставляем найденные показатели в экспоненты:

```math
e^{iz}=e^{-kx+imx},
```

```math
e^{-iz}=e^{kx-imx}.
```

Используем свойство $e^{a+b}=e^ae^b$:

```math
e^{iz}=e^{-kx}e^{imx},
```

```math
e^{-iz}=e^{kx}e^{-imx}.
```

Множители $e^{-kx}$ и $e^{kx}$ являются вещественными. Чтобы раскрыть оставшиеся комплексные экспоненты, применяем формулу Эйлера.

```math
e^{i\varphi}=\cos\varphi+i\sin\varphi.
```

При $\varphi=mx$:

```math
e^{imx}=\cos(mx)+i\sin(mx).
```

При $\varphi=-mx$, учитывая чётность косинуса и нечётность синуса:

```math
e^{-imx}=\cos(mx)-i\sin(mx).
```

Подставляем эти выражения в ранее полученные формулы:

```math
e^{iz}=e^{-kx}\bigl(\cos(mx)+i\sin(mx)\bigr).
```

```math
e^{-iz}=e^{kx}\bigl(\cos(mx)-i\sin(mx)\bigr).
```

##### Завершаем преобразование комплексного косинуса

Ранее мы получили формулу:

```math
\cos z=\frac{e^{iz}+e^{-iz}}{2}.
```

Подставляем в неё найденные выражения $e^{iz}$ и $e^{-iz}$:

```math
g(x)=
\frac{
e^{-kx}\bigl(\cos(mx)+i\sin(mx)\bigr)
+
e^{kx}\bigl(\cos(mx)-i\sin(mx)\bigr)
}{2}.
```

Раскрываем скобки:

```math
g(x)=
\frac{
e^{-kx}\cos(mx)
+i e^{-kx}\sin(mx)
+e^{kx}\cos(mx)
-i e^{kx}\sin(mx)
}{2}.
```

Собираем отдельно слагаемые без $i$:

```math
\cos(mx)\frac{e^{kx}+e^{-kx}}{2}.
```

Собираем отдельно слагаемые, содержащие $i$:

```math
i\sin(mx)\frac{e^{-kx}-e^{kx}}{2}.
```

Выносим знак минус из разности, используя тождество $A - B = -(B - A)$:

```math
i\sin(mx)\frac{e^{-kx}-e^{kx}}{2}
=
-i\sin(mx)\frac{e^{kx}-e^{-kx}}{2}.
```

Поэтому:

```math
g(x)
=
\cos(mx)\frac{e^{kx}+e^{-kx}}{2}
-
i\sin(mx)\frac{e^{kx}-e^{-kx}}{2}.
```

В полученном выражении присутствуют сумма и разность экспонент:

```math
\frac{e^{kx}+e^{-kx}}{2},
```

```math
\frac{e^{kx}-e^{-kx}}{2}.
```

Данные выражения являются гиперболическим косинусом и гиперболическим синусом по их определению:

```math
\cosh t=\frac{e^t+e^{-t}}{2}.
```

```math
\sinh t=\frac{e^t-e^{-t}}{2}.
```

В нашем случае $t=kx$, поэтому обозначим $t$ как $kx$:

```math
\cosh(kx)=\frac{e^{kx}+e^{-kx}}{2}.
```

```math
\sinh(kx)=\frac{e^{kx}-e^{-kx}}{2}.
```

Используем эти обозначения, чтобы записать результат короче:

```math
g(x)=\cos(mx)\cosh(kx)-i\sin(mx)\sinh(kx).
```

Получили выражение вида $u(x)+iv(x)$. Поэтому:

```math
\mathrm{Re}g(x)=\cos(mx)\cosh(kx).
```

```math
\mathrm{Im}g(x)=-\sin(mx)\sinh(kx).
```

##### Подстановка постоянных

Подставим $m=2$ и $k=17$ в полученные формулы.

Для комплексной экспоненты:

```math
\mathrm{Re}f(x)=e^{2x}\cos(17x),
\qquad
\mathrm{Im}f(x)=e^{2x}\sin(17x).
```

Для комплексного косинуса:

```math
\mathrm{Re}g(x)=\cos(2x)\cosh(17x),
\qquad
\mathrm{Im}g(x)=-\sin(2x)\sinh(17x).
```

##### Проверка полученных формул

Сравним аналитические формулы с непосредственным вычислением комплексных функций в нескольких точках.

##### Выбираем отрезок для комплексной экспоненты

Ранее мы получили:

```math
\mathrm{Re}f(x)=e^{2x}\cos(17x).
```

```math
\mathrm{Im}f(x)=e^{2x}\sin(17x).
```

Функции $\cos(17x)$ и $\sin(17x)$ отвечают за колебания. Так найдём их период.

Синус и косинус повторяют значения, когда их аргумент увеличивается на полный оборот $2\pi$. Поэтому период $T$ удовлетворяет равенству:

```math
17T=2\pi.
```

Следовательно:

```math
T=\frac{2\pi}{17}=0.37.
```

Так как $T$ у нас небольшой ($0.37$), предпочитаю выбрать небольшой отрезок: $[-1,1]$.

Его длина равна $2$. Количество периодов на этом отрезке равно:

```math
\frac{2}{T}
=
\frac{2}{2\pi/17}
=
\frac{17}{\pi}
=
5.41.
```

Следовательно, на отрезке $[-1,1]$ видно больше пяти колебаний.

Множитель $e^{2x}$ определяет амплитуду колебаний. На концах выбранного отрезка он принимает значения:

```math
e^{-2}=0.135,
```

```math
e^2=7.389.
```

Поэтому на графике будет видно, что слева амплитуда мала, а при движении вправо она увеличивается. Отрезок $[-1,1]$ показывает как колебания, так и изменение их амплитуды.

### Строим графики частей комплексной экспоненты

На одном рисунке построим две требуемые функции:

```math
y_1(x)=\mathrm{Re}f(x)=e^{2x}\cos(17x),
```

```math
y_2(x)=\mathrm{Im}f(x)=e^{2x}\sin(17x).
```

Вещественную часть изображена бордовым цветом, мнимая – красным. Пунктирными линиями – ограничения функции.

```math
y=\pm e^{2x}.
```

##### Комментарий к графику комплексной экспоненты

Таким образом, на отрезке $[-1,1]$ видно более пяти колебаний и изменение их размаха, которое определяется множителем $e^{2x}$. Больший отрезок брать нецелесообразно: из-за быстрого роста экспоненты часть графика с малыми значениями станет плохо различимой. Если движение идет вправо, то размах увеличивается, а при движении влево уменьшается. Вещественная и мнимая части сдвинуты относительно друг друга, поскольку множители $\cos(17x)$ и $\sin(17x)$ отличаются по фазе.

##### Выбираем отрезки для комплексного косинуса

Ранее мы получили:

```math
\mathrm{Re}g(x)=\cos(2x)\cosh(17x),
```

```math
\mathrm{Im}g(x)=-\sin(2x)\sinh(17x).
```

Множители $\cosh(17x)$ и $\sinh(17x)$ быстро растут при увеличении $|x|$. Поэтому сначала выберем отрезок $[-1,1]$, чтобы показать общий характер роста функций.

На этом отрезке также находятся ближайшие к нулю корни вещественной части:

```math
\cos(2x)=0.
```

Следовательно,

```math
2x=\frac{\pi}{2}+\pi n,
```

```math
x=\frac{\pi}{4}+\frac{\pi n}{2}.
```

Ближайшие к нулю корни равны

```math
x=\pm\frac{\pi}{4}.
```

Из-за быстрого роста гиперболических функций поведение около нуля на общем графике плохо различимо. Поэтому дополнительно построим увеличенный график на отрезке $[-0.25,0.25]$.

##### Строим графики частей комплексного косинуса

Строим две функции:

```math
y_1(x)=\mathrm{Re}g(x)=\cos(2x)\cosh(17x),
```

```math
y_2(x)=\mathrm{Im}g(x)=-\sin(2x)\sinh(17x).
```

На левом графике покажем общее поведение функций на $[-1,1]$, а на правом — их поведение около нуля на $[-0.25,0.25]$.

#### Вывод
Получены и построены все 4 требуемые вещественные функции. Первый рисунок показывает колебания комплексной экспоненты и изменение их амплитуды. Второй рисунок показывает быстрый рост частей комплексного косинуса и их поведение около нуля.
